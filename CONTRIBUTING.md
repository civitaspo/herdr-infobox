# Contributing

Use English in issues, pull requests, commits, and documentation. Open an issue for substantial changes, keep pull requests focused, and use Conventional Commit pull request titles.

Install tools with `mise install --locked`, then run `mise run lint`, `mise run test`, and `mise run build`. Sign commits and submit a pull request; main accepts squash merges only.

Do not commit credentials. Report vulnerabilities through private reporting as described in SECURITY.md. Release pull requests require an explicit maintainer merge.
